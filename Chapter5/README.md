# Chapter 5: Express.js Basics & Middleware Flow

## Overview

This chapter introduces **Express.js** and focuses on understanding how middleware works, how routes are handled, and how form data is processed using middleware. It demonstrates how Express simplifies backend development compared to core Node.js.

## Key Concepts Learned

- Setting up an Express application
- Understanding middleware execution order
- Using multiple middleware functions
- Handling GET and POST routes
- Creating simple HTML responses with Express
- Processing form data using `body-parser`
- Using `next()` to control request flow

## What This Chapter Demonstrates

- Global middleware for logging requests
- Route-level middleware for specific endpoints
- Form submission handling via POST requests
- Clean separation between request processing and response handling
- Automatic request body parsing using middleware

## Learning Outcome

By completing this chapter, I gained a clear understanding of:

- How Express handles requests internally
- Why middleware is a core concept in Express
- How data flows from request → middleware → response
- How Express improves code readability and scalability

## Technologies Used

- Node.js
- Express.js
- body-parser
